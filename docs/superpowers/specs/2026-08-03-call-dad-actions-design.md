# “叫爸爸”动作替换设计

## 目标

把动作中心中意义较弱的单人“趴下睡觉”替换为“叫爸爸”，并把“四人集合玩耍”替换为“四人一起喊爸爸”。菜单名称、类型标识、动作反馈、运行行为和自检必须保持一致。

## 行为

- 单人动作显示为 `📣 叫爸爸`，说明为“原地弹跳并喊一声爸爸”。人物执行一次短促弹跳，并显示 `爸爸！` 气泡。
- 集体动作显示为 `📣 四人一起喊爸爸`。四人会被召回并集合，每个人同时显示 `爸爸！` 气泡。
- 全局暂停、隐藏人物召回、菜单入口和错误反馈继续沿用现有动作中心规则。
- 自主行为中的随机睡觉不受影响；本次只替换用户手动触发的睡觉动作。
- 本阶段不加入音频，避免额外资源、音量和系统权限问题。未来可以在同一类型化动作入口上增加可选语音。

## 架构

`PetActionID.sleep` 改为 `callDad`，`gatherPlay` 改为 `groupCallDad`。动作目录提供全部用户文案；世界层将单人动作映射到现有跳跃运动，将集体动作映射到现有集合行为；窗口协调层继续根据动作结果向所有受影响人物显示反馈。

## 验收

- 所有菜单不再出现“趴下睡觉”或“四人集合玩耍”。
- 类型化动作目录仅暴露新的两个 ID 和文案。
- 单人动作进入跳跃状态并在规定时间后恢复。
- 集体动作影响四个人，并向四个人显示 `爸爸！`。
- 完整测试、Release 构建、应用自检、签名和运行窗口检查通过。
