② 架构现状：一份核心，两端外壳

DesktopPetsCore（共享核心，纯 Foundation） PetWorld 模拟 · ObstacleMap 几何 · 名册持久化 · 动作目录 · 确定性随机 —— 双端逐位一致
DesktopPets（macOS 壳 · AppKit） NSPanel 分层窗口 · 状态菜单 · 控制总台 · NSImage 头像管线 · DMG 分发
WindowsShell（Windows 壳 · Win32） WS_EX_LAYERED 透明窗口 · PetCanvas 软件光栅器（与 Mac 同比例同配色）· UpdateLayeredWindow 逐帧提交 · 便携 zip 分发
CoreProbe 是双端共享的可执行自检；ShellModel 的 tick/坐标映射与 macOS PetWindowCoordinator 同语义；Windows 上 4 只宠物各自独立透明窗口，置顶、点击穿透、20fps 模拟。

③ 本次迭代修复的问题（均已固化进仓库）

#问题修复
1Win32 代码不匹配 swift-win-sdk 类型约定（BOOL/宽字符串/常量类型）Array<WCHAR> 宽字符串 + withUnsafeBufferPointer 传 LPCWSTR；DWORD/UINT/INT32 精确类型
2CreateDIBSection 用法错误（SetDIBits 误用）显式 bits 指针 + memcpy，DIB 直接对接 UpdateLayeredWindow
3PeekMessageW 在 swift-win-sdk 返回 Bool 而非 Int去掉整型比较，直接布尔循环
4SwiftPM 不支持一条命令多 --productCI 拆分为两次 swift build

④ 用户视角：Windows 用户怎么用

从 Release 下载 DesktopPets-windows-x64.zip → 解压 → 双击 DesktopPets.exe。 4 只桌面宠物出现在屏幕底部爬行，置顶显示、不挡操作。zip 内已带 Swift 运行时 DLL，无需安装任何依赖。
⚠️ 已知边界：未签名 exe 可能触发 SmartScreen 提示（与 Mac 端 Gatekeeper 同理，README 已说明）；多显示器/托盘菜单/开机自启为下一迭代项。
