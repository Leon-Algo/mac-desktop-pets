④ 风险与注意（路线 B 固有）

  • Gatekeeper 警告不可避免：从 GitHub 下载的 DMG/.app 带 com.apple.quarantine 标记，首次打开会被拦。这是路线 B 的固有代价。
  • 解除方式（写进 README）：右键 → 「打开」；或终端执行 xattr -dr com.apple.quarantine /Applications/DesktopPets.app。
  • 源码编译路径零摩擦：git clone + swift build -c release 本地编译的 app 不受 quarantine，适合开发者。
  • 保留 ad-hoc 签名：package-app.sh 维持 --sign -，保证二进制完整性；它不改变 Gatekeeper 行为，但仍是好习惯。
  • DMG 也建议 ad-hoc 签名：虽不消除警告，但保证传输完整。
