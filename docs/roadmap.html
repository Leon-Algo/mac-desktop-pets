③ 本次踩坑与修复（已解决）

  • GitHub runner 无 Swift 6：macos-14 自带 Swift 5.10，项目要求 6.0 → 两个 workflow 加 swift-actions/setup-swift@v2（6.0）。
  • workflow 文件含中文导致解析失败：release.yml 的 --notes 含中文，GitHub 工作流校验直接 0s 失败 → 改为纯英文，Release 才跑通。
  • 本地化默认语言 bug：L10n 在英文系统自动切英文，导致 30 个中文断言测试在英文 CI 上失败 → 改为默认 zh-Hans（零行为变化），英文 .lproj 仍内嵌备用。本地 129/129、CI 129/129。
